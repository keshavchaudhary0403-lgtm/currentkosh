# Global indices CurrentKosh covers

Only these. They are the global rankings that UPSC, State PSC, SSC and Banking papers repeatedly ask about.
Write each from the **publisher's own page or report** (the domain listed), with `sourceId: "intl"`, `category:
"reports_indices"`. State India's rank (and the previous edition's, if the page gives it), score, the top 1–3
countries, and what the index measures. Never use newspaper, coaching or Wikipedia text.
Neutral wording: if India's government has publicly disputed an index and an official Indian source says so, you may
add one line citing that source; otherwise don't characterise the index.
